# 🏭 وبسایت صنعت آکادمی

## 📖 راهنمای ساده برای اجرا

### ⚡ روش اول: ساده‌ترین روش (بدون نیاز به هیچ برنامه‌ای)

1. بعد از دانلود پروژه از GitHub، وارد پوشه `public` بشید
2. فایل **`standalone.html`** رو پیدا کنید
3. روی اون **دابل‌کلیک** کنید
4. ✅ وبسایت در مرورگر شما باز میشه!

> این فایل یک وبسایت کامل و مستقل هست که بدون نیاز به هیچ برنامه اضافی کار می‌کنه.

---

### 🔧 روش دوم: اجرای پروژه کامل (برای توسعه‌دهنده‌ها)

اگر می‌خواید پروژه React رو اجرا کنید:

**مرحله 1:** نصب Node.js از سایت https://nodejs.org (نسخه LTS)

**مرحله 2:** باز کردن ترمینال (CMD یا PowerShell) در پوشه پروژه

**مرحله 3:** نصب وابستگی‌ها:
```
npm install
```

**مرحله 4:** اجرای سرور توسعه:
```
npm run dev
```

**مرحله 5:** باز کردن مرورگر روی آدرس:
```
http://localhost:3000
```

---

### 📦 روش سوم: ساخت نسخه نهایی

```
npm run build
```

بعد از اتمام، فایل‌های نهایی در پوشه `dist` قرار می‌گیرن.
فایل `dist/index.html` رو در مرورگر باز کنید.

---

## 📁 ساختار پروژه

```
sanat-academic/
├── public/
│   └── standalone.html    ← ✅ فایل مستقل (بدون نیاز به build)
├── src/
│   ├── App.tsx            ← فایل اصلی React
│   ├── components/        ← کامپوننت‌ها
│   └── index.css          ← استایل‌ها
├── dist/                  ← خروجی build (بعد از npm run build)
├── index.html             ← قالب HTML
└── README.md              ← همین فایل
```
